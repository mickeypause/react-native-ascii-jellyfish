# skia-ascii-jelly-fish

## About

I made animated ASCII jellyfish in React Native using **React Native Skia** and **Reanimated**. Three jellyfish pulse, turn, and drift through a full-screen ocean, rendered entirely from ASCII characters and running smoothly at **60 FPS** in the iOS simulator.

## Quick start

### Requirements

- Node.js 24.3 or newer within the 24.x release line, with npm.
- **iOS native build:** macOS, Xcode 26.4 or newer, and an installed iOS simulator runtime.
- **Android native build:** Android Studio, the Android SDK, JDK 17, and an emulator or connected device with USB debugging enabled.

Install the dependencies:

```sh
npm install
```

### Native build

Run on an iOS simulator:

```sh
npm run ios
```

Run on an Android emulator or connected device:

```sh
npm run android
```
